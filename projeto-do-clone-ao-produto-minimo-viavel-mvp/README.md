# 🚗 VelocDrive - Car Rental System
> Sistema web de aluguel de carros de luxo desenvolvido com foco em experiência visual, responsividade e interatividade.

---

### 📌 Sobre o Projeto
O **VelocDrive** é uma aplicação web criada para simular uma plataforma moderna de aluguel de veículos premium. O projeto foi desenvolvido com o objetivo de fortalecer habilidades em desenvolvimento Front-End, estruturação de interfaces e criação de experiências responsivas utilizando tecnologias web puras.
